# Vest Personal AI Assistant

Личный ИИ-ассистент (Hermes Agent на устройстве владельца), интегрированный с Google Calendar API.

**Назначение:** управление личным календарём владельца (просмотр, создание, удаление событий).

**Использование:** строго личное, единственный пользователь — владелец аккаунта.
